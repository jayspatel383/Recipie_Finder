#  Recipe Finder

A React web app that lets users search for recipes, view detailed cooking instructions, and save their favorite recipes to a personal list.

Built with React + Vite, Spoonacular API for recipe data, and Supabase for authentication and favorites storage.



## How to Run This Project

Everything is pre-configured. No API keys needed. No Supabase setup needed.

### Prerequisites

- Node.js v18 or higher — check your version with:
  ```bash
  node -v
  ```
  If you don't have it, download it from https://nodejs.org

### Step 1 — Clone the repository

1. download the zip file and extract it .
2. open the file in vs code

3. open terminal and follow the below instructions 

### Step 2 — Install dependencies

npm install

### Step 3 — Run the app

npm run dev

Open the URL shown in the terminal (usually http://localhost:5173) in your browser.

That's it. The app is fully functional with all keys pre-configured.
